# QuizFlags — «Флаги за минуту»

Android-приложение в формате викторины: угадать как можно больше государственных флагов за 60 секунд, имея 3 жизни. Курсовой проект.

---

## 📱 Что умеет приложение

- **Игра:** 60 секунд, 3 жизни, +1 очко за правильный ответ, −1 жизнь за ошибку. Флаги и варианты ответов показываются в случайном порядке, без повторов в рамках одной игры.
- **Авторизация (мок):** вход по логину/паролю без сервера, данные хранятся локально. Есть режим гостя с автоматически сгенерированным именем `гость_XXX`.
- **Просмотр всех флагов:** отдельный экран-справочник со сеткой «флаг + название».
- **Статистика:** история игр (дата, очки, причина завершения).
- **Таблица лидеров:** топ-10 игроков по максимальному счёту.
- **Сброс статистики:** полная очистка истории игр.
- **О программе:** краткая информация о приложении.
- **Выход:** выход из аккаунта (или закрытие приложения для гостя).

## 🏗️ Архитектура

- **Язык:** Kotlin
- **UI:** Jetpack Compose + Material 3
- **Паттерн:** MVVM + Repository
- **Асинхронность:** Kotlin Coroutines + Flow (`StateFlow` для UI, `SharedFlow`/`Channel` для одноразовых событий навигации)
- **Навигация:** Navigation Compose с типизированными роутами (`sealed class Routes`)
- **Хранение данных:**
  - **Room** — флаги (предзаполнены из `assets/flags.json`) и статистика игр
  - **DataStore Preferences** — имя пользователя, статус авторизации, ID гостя
- **Загрузка изображений:** Coil (`AsyncImage`)
- **DI:** вручную — через `QuizApplication` (без Hilt/Dagger)

## 🚀 Сборка и запуск

### Требования
- Android Studio Hedgehog (2023.1.1) или новее
- JDK 17
- Android SDK 36
- Эмулятор или устройство на Android 8.0+

### Шаги

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/yagor-kt/QuizFlags.git
   cd QuizFlags
   ```

2. Открыть проект в Android Studio (**Open** → выбрать папку).

3. Дождаться синхронизации Gradle.

4. Собрать:
   ```bash
   ./gradlew assembleDebug
   ```
   или нажать ▶ **Run** в Android Studio.

## 🎮 Правила игры

| Параметр | Значение |
|---|---|
| Длительность раунда | 60 секунд |
| Жизни | 3 |
| Правильный ответ | +1 очко, следующий флаг |
| Неправильный ответ | −1 жизнь, следующий флаг |
| Конец игры | 0 жизней **или** 0 секунд |
| Порядок флагов | случайный, без повторов |
| Порядок вариантов | случайный (1 правильный + 3 чужих) |
| Имя игрока | логин из DataStore **или** `гость_XXX` |

Результат **всегда** сохраняется в статистику и участвует в таблице лидеров.

## 🧩 Принятые решения

- **Авторизация — мок.** Пароль никуда не отправляется, хранится только логин. Это осознанное упрощение для курсового проекта.
- **Без интернета.** Все данные локальные: Room + DataStore.
- **Только русский язык.** Никакой мультиязычности.
- **Result — отдельный экран** (а не диалог), чтобы показать навигацию с аргументами (`score`, `reason`).
- **Гость генерируется каждый раз новый** — по требованию заказчика.
