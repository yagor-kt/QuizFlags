\# QuizFlags — «Флаги за минуту»



Курсовой проект: Android-приложение-викторина, в которой игрок угадывает флаги стран.

За отведённую минуту нужно набрать максимум очков. Игра заканчивается, когда истекает

время или заканчиваются жизни.



\## Стек



\- Kotlin + Jetpack Compose (Material 3), MVVM

\- Room (KSP) для хранения флагов и статистики

\- DataStore Preferences для настроек пользователя

\- Coil для загрузки изображений

\- Navigation Compose для навигации между экранами

\- Работает полностью офлайн, интернет не требуется



\## Сборка



1\. Откройте проект в Android Studio (JDK 17).

2\. Дождитесь синхронизации Gradle.

3\. Запустите на устройстве/эмуляторе с Android 7.0+ (minSdk 24).



\## Флаги (PNG)



Сами файлы изображений в репозиторий НЕ входят — их нужно положить вручную

в каталог `app/src/main/assets/flags/`.



Названия файлов должны совпадать со значением поля `imageName` из

`app/src/main/assets/flags.json`:

```

app/src/main/assets/flags/ru.png

app/src/main/assets/flags/us.png

app/src/main/assets/flags/ua.png

```



Каждое изображение — PNG-флаг страны, названный по ISO-коду страны

в нижнем регистре. Список стран и их кодов смотрите в `flags.json`.
